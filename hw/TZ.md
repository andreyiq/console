# ТЗ — консоль v2 (F133-A)

Что должно быть на плате. Как это делать и почему — в [BOARD.md](BOARD.md).

## Что это

Портативная игровая консоль-игрушка: NES-эмулятор на bare-metal Rust, экран
3.5", геймпад, звук, аккумулятор. Плата учебная — читаемость схемы важнее
плотности монтажа.

## Состав

| Узел | Что | Заметки |
|---|---|---|
| **Мозг** | Allwinner F133-A, eLQFP128 14×14 мм | DDR2 64 МБ внутри корпуса — внешней памяти нет |
| **Плата** | **2 слоя** | обязательное ограничение: пробуем травить дома. См. BOARD.md §7 |
| **Такт** | кварц 24 МГц, CL=18 pF | 32.768 кГц не нужен |
| **Питание** | три buck'а `SY8089AAAC`: 3.3 / 1.8 / 0.9 В | номиналы делителей проверены, BOARD.md §3. Резерв — `RY1303` |
| **Экран** | 3.5" IPS ILI9488, 480×320, FFC 40 pin 0.5 мм | |
| **Подсветка** | boost-драйвер тока `SY7201ABC` от +5 В | 75 мА, яркость ШИМ'ом на вход `EN/PWM` (PD22). Просто MOSFET не годится — см. BOARD.md §4 |
| **Кнопки игровые** | 10: ↑ ↓ ← →, A, B, C, D, Start, Select | тактовые PTS645, кнопка между пином и GND. C/D — на вырост под Sega |
| **Кнопки служебные** | Reset, FEL (вход в режим прошивки) | |
| **Питание вкл/выкл** | контроллер кнопки `LTC2954-1` + тактовая кнопка | нажал — включилось, нажал — прошивка сохранилась и выключилась, держишь 3 с — снимается железом. См. BOARD.md §3 |
| **Аварийный рубильник** | движковый `SW1` последовательно с `VIN` контроллера | физически обесточивает всё, если прошивка повисла. Через него текут микроамперы |
| **Звук** | кодек F133 → `PAM8301` → динамик | громкость программная, регулятора нет |
| **Динамик** | 8 Ω, 1–2 Вт, овал ~20×40 мм или круг 28 мм | **подобрать заново**, текущий звучит плохо. Критерии — BOARD.md §6 |
| **Хранение** | слот microSD + **SPI NOR `W25Q32`** | прошивка на флешке, карта только под ROM'ы. Загрузка без карты |
| **Защита от статики** | `ESD9B3.3ST5G` на `D+`/`D−` и на microSD | разъёмы торчат наружу, пальцы приносят до 15 кВ |
| **Заряд** | USB-C, зарядник Li-Ion 1 A, LiPo-аккумулятор 1500–2000 мАч | ~2 часа игры |
| **Прошивка** | USB-C **16P** (с D+/D−) — FEL через `xfel` | в v1 стоял 6P power-only, так нельзя |
| **Отладка** | гребёнка UART, 4 пина 2.54 мм: `GND / TX / RX / 3V3` | под USB-TTL свисток CH340/CP2102, 115200 8N1. Мост на плату не ставить |
| **Отладка 2** | 4 пина JTAG на `PE4..PE7` (`TMS/TDI/TDO/TCK`) | не занимать кнопками; можно просто площадки, без гребёнки |
| **Под первый запуск** | перемычки 0 Ω на каждой рельсе, контрольные точки, земляные петли | без этого нельзя проверить питание до пайки F133. См. BOARD.md §9 |
| **Индикация** | светодиоды: питание, заряд, заряд окончен | |
| **Телеметрия** | напряжение батареи на GPADC | чтобы рисовать уровень заряда на экране |

## Требования

1. **Играть, пока заряжается.** Power path: USB и батарея одновременно, без
   отключения консоли при втыкании кабеля.
2. **Стартует без карты — да.** Прошивка живёт на SPI NOR `W25Q32`, microSD
   нужна только под ROM'ы и сейвы и форматируется как угодно.
3. **Заливка прошивки без разбора корпуса** — USB-C + кнопка FEL снаружи.
4. **Правильная последовательность питания.** F133 требует 1.8 В → 3.3 В →
   пауза → 0.9 В → и только потом отпустить RESET. Переключатель вкл/выкл
   должен запускать эту цепочку целиком, а не просто рвать один рельс.
5. **Экран разводить сразу под оба интерфейса — SPI и i8080 16-бит.** Оба уже
   выведены на один FFC-40, переключаются страпами IM0/IM1/IM2. Софт стартует
   на SPI (код готов), потом переезжает на 8080 без перепайки. Стоит 6 лишних
   пинов, см. BOARD.md §4.
6. **Автономность** — ориентир 1–1.5 Вт потребления, 2 часа игры.
7. **Форм-фактор** — держать в двух руках: экран сверху по центру, D-pad слева,
   A/B/C/D справа, Start/Select снизу по центру.
8. **Плата должна запускаться по частям.** F133 — самая дорогая и трудная в
   замене деталь, подавать на неё непроверенные рельсы нельзя. Минимум для
   проверки «процессор жив» — питание, кварц, `RESET` и USB: без карты и без
   флешки BROM сам уходит в FEL, и `xfel version` отвечает. Отсюда
   обязательные элементы схемы: **перемычки 0 Ω последовательно с каждой
   рельсой**, контрольные точки на всех рельсах, несколько земляных точек,
   boot-страпы перемычками, питание необязательных узлов через 0 Ω, гребёнка
   UART и кнопки `RESET`/`FEL` по краю платы, работа без батареи.
   Подробный порядок этапов — BOARD.md §9.

### Звуковой тракт (повторяем MangoPi, этап 14 работает)

```
FIFO → ЦАП кодека F133 → HPOUTL/R (пины 98/99)
  → C 10 мкФ (развязка) → R 150K (пассивное суммирование L+R в моно)
  → PAM8301 → динамик
```

- Усилитель нужен потому, что `HPOUTL/R` рассчитаны на наушники 32 Ω; динамик
  8 Ω они не раскачают.
- Выход `PAM8301` **мостовой (BTL)**: динамик висит между двумя пинами, землю
  ни на один из них сажать нельзя.
- `PAM8301` моно — это правильно, динамик один. L и R складываются пассивно.
- Сверх MangoPi: вход `SHDN` усилителя завести на GPIO — глушить звук и убрать
  щелчок при старте.

### USB-C 16P

`P` = число реальных контактов. 6P = только питание (как в v1), 16P = питание +
USB 2.0 (D+/D−), 24P = ещё и SuperSpeed. Нужен **16P**, символ KiCad
`USB_C_Receptacle_USB2.0_16P`. Разъём переворачиваемый, поэтому D+/D− выведены
дважды — обе пары соединяются вместе, это штатно. CC1/CC2 через 5.1k на GND.

## Чего в ТЗ **нет** (сознательно)

Wi-Fi, Bluetooth, разъём наушников, вибромотор, второй геймпад, видеовыход
CVBS, Ethernet, камера, тачскрин (панель его умеет — резистивный, но игре он не
нужен).

## Что ты, возможно, забыл

Из твоего списка выпало вот это — я добавил в состав выше, но помечаю явно,
чтобы ты подтвердил или вычеркнул:

- **microSD** — без неё нечем загружаться и негде хранить игры. Самый важный
  пропуск.
- **D+/D− на USB-C.** В v1 стоял 6-пиновый power-only разъём. Тогда прошивка
  заливается только… никак. Нужен 16P.
- **Кнопка FEL и кнопка Reset** — иначе перепрошивка через разбор корпуса.
- **Гребёнка UART** — единственный отладочный вывод, весь `println!` идёт туда.
- **Драйвер подсветки.** 3.5" ест 75 мА только на подсветку — это заметная доля
  бюджета батареи, и просто транзистором её не включить: у панели `LED-A` =
  3.2 В типовых, от 3.3 В рельса остаётся 0.1 В запаса. Нужен буст со
  стабилизацией тока.
- **Усилитель для динамика.** Выход кодека — наушниковый, динамик 8 Ω напрямую
  не потянет. Нужен класс-D (PAM8301 как на MangoPi).
- **Измерение напряжения батареи** (GPADC0, пин 101, домен AVCC 1.8 В —
  делитель считать под 1.8 В, не под 3.3).
- **Индикация заряда** — два светодиода зарядника (CHRG/STDBY).
- **ESD-защита на USB.** Разъём торчит наружу, D+/D− идут прямо в SoC. На
  Xassette-Asterisk на каждую линию стоит `ESD9B3.3ST5G` — копейки, а пробой
  USB убивает чип целиком.
- **Защита аккумулятора** от переразряда/КЗ — либо банка со встроенной платой
  защиты, либо ставить свою.
- **Boot-страпы PC4/PC5** — определяют, откуда BROM грузится. Через 10k, чтобы
  не мешать шине SPI0.
- **Крепёж и механика** — монтажные отверстия, высота кнопок над платой,
  посадка экрана, размер платы под 3.5" (~86×56 мм активная область + рамка).

## Открытые вопросы (решить до схемы)

1. ~~Чем делать питание?~~ **Решено: три `SY8089AAAC` + TP4056 + power path на
   PMOS.** Номиналы делителей и секвенсор — BOARD.md §3. AXP2101 проверен и
   отпал. `RY1303` записан как вариант 2 — вернуться к нему, если SY8089 не
   купится.
2. ~~Батарея в первой ревизии нужна?~~ **Решено: да.** Разводим TP4056 +
   power path + защиту сразу, а не «посадочные места на будущее».
3. ~~SPI NOR флешка?~~ **Решено: ставим `W25Q32` на `PC2..PC7`**, референс в
   `hw/ref/Xassette-Asterisk`. С SPI-режимом дисплея делят шину, но CS у них
   разные — уживаются.
4. ~~Кнопки на PE4–PE7 конфликтуют с JTAG.~~ **Решено: кнопки на банк PG.**
   `PE4/PE5/PE6/PE7` — единственный выход R-JTAG наружу (`TMS/TDI/TDO/TCK`,
   значение мукса `0111`). Сейчас на макете на PE7 висит START — на плате
   переезжает на PG. PE4–PE7 оставляем свободными и выводим на гребёнку.
5. ~~A/B/C/D или только A/B?~~ **Решено: четыре, на вырост под Sega.**
6. ~~Переключатель питания механический или «умный»?~~ **Решено: готовый
   контроллер `LTC2954-1` плюс движок как аварийный рубильник.** Дискретная
   защёлка отменена — она не переживает Hi-Z на GPIO при сбросе. Обе схемы
   сходятся на одну цепь `PWR_EN` → `EN` первого buck'а. Развести `KILL` (PG10)
   и `INT` (PG11). См. BOARD.md §3.
7. ~~1.8 В внешним buck'ом или встроенными LDOA/LDOB?~~ **Решено: внешним
   buck'ом.** Потолок рабочей температуры DRAM 85 вместо 70 °C стоит одного
   индуктора. `LDOA-OUT`/`LDOB-OUT` только развязать конденсаторами.
8. ~~ESD-защита?~~ **Решено: ставим** на `D+`/`D−` и microSD.
9. ~~Сколько слоёв?~~ **Решено: 2.** Ограничение жёсткое — пробуем травить
   дома, см. BOARD.md §7.

### Осталось нерешённым

10. **Закупка.** Проверить наличие и взять решение: `SY8089AAAC` ×3 (иначе
    `RY1303`), `LTC2954` именно версии **`-1`** (у `-2` выход инверсный, к нему
    нужен PMOS-инвертор +3 детали; запасной путь — `MAX16054`, но он не умеет
    корректно выключаться кнопкой), `SY7201ABC`, `PAM8301`, `W25Q32`.
11. **Динамик** — подобрать заново, критерии в BOARD.md §6.
12. **Защита аккумулятора**: банка с готовой платой защиты или своя на
    `DW01` + `8205A`. Плюс тип разъёма батареи.
13. **Механика**: размер платы, расположение кнопок, корпус, монтажные
    отверстия, высота кнопок над платой.

## Проверка бюджета пинов

Сходится с запасом:

| Потребитель | Пины | Сколько |
|---|---|---|
| Экран i8080 16-бит | PB2–PB5, PD0–PD21 | ~20 |
| Экран SPI (вторым режимом) | SPI0 + 3 страпа IM, свой CS | 6 |
| SPI NOR `W25Q32` | PC2–PC7 (та же шина SPI0, свой CS) | 6 |
| microSD (SDC0 + DET) | PF0–PF6 | 7 |
| UART0 | PE2, PE3 | 2 |
| Игровые кнопки | PG0–PG9 | 10 |
| Подсветка PWM | PD22 (PWM7) | 1 |
| `SHDN` усилителя | любой GPIO | 1 |
| Boot-страпы | PC4, PC5 — те же линии SPI0, через 10k | 0 |
| Питание: `KILL` / `INT` контроллера кнопки | PG10, PG11 | 2 |
| JTAG (площадки, на вырост) | PE4–PE7 | 4 |
| Звук, USB, ADC, RESET, кварц | выделенные пины чипа | — |
| **Свободно** | PG12–PG15, PE0–PE1, PE8–PE13, PC0–PC1 | ~14 |
