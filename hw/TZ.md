# ТЗ — консоль v2 (F133-A)

Что должно быть на плате. Микросхемы и почему именно они — в
[CHIPS.md](CHIPS.md). Распиновка, номиналы и порядок запуска — в
[BOARD-draft.md](BOARD-draft.md).

## Что это

Портативная игровая консоль-игрушка: NES-эмулятор на bare-metal Rust, экран
3.5", геймпад, звук, аккумулятор. Плата учебная и в одном экземпляре —
читаемость схемы важнее плотности монтажа.

## Состав

| Узел | Что |
|---|---|
| **Мозг** | Allwinner F133-A, eLQFP128 14×14 мм. DDR2 64 МБ внутри корпуса |
| **Плата** | 2 слоя — пробуем травить дома |
| **Такт** | кварц 24 МГц и кварц 32.768 кГц для RTC, нагрузочные ёмкости под оба |
| **Питание** | три buck'а `SY8089AAAC`: 3.3 / 1.8 / 0.9 В |
| **Вкл/выкл** | движковый выключатель в цепи `PWR_EN` |
| **Экран** | 3.5" IPS ILI9488, 480×320, FFC 40 pin 0.5 мм |
| **Подсветка** | `LED-A` на +3V3 через резистор, катоды через MOSFET на `PD22` (ШИМ) |
| **Кнопки игровые** | 10: ↑ ↓ ← →, A, B, C, D, Start, Select. `PTS645`, кнопка между пином и GND |
| **Кнопки служебные** | Reset и FEL — **не кнопки, а пары контактных площадок** под пинцет. Кнопок нет ни в одном серийном устройстве этого класса, а у нас есть движок питания (сброс) и загрузка с карты первым приоритетом (FEL). Разбор — console/blocks/03-usb.md §1 |
| **Звук** | кодек F133 → `PAM8301` → динамик, питание усилителя от `VSYS` |
| **Динамик** | 8 Ω, 1–2 Вт — подобрать заново, текущий звучит плохо |
| **Хранение** | слот microSD + SPI NOR `W25Q32` (прошивка на флешке, ROM'ы на карте) |
| **Защита от статики** | `USBLC6-2SC6` на `D+`/`D−`. На microSD не ставим |
| **Заряд** | USB-C, `TP4056`, `PROG` = 1.1k (1 А), LiPo 1500–2000 мАч |
| **Аккумулятор** | **банка со встроенной платой защиты** — проверить при покупке |
| **Прошивка** | USB-C 16P (с `D+`/`D−`), FEL через `xfel` |
| **Отладка** | гребёнка UART 4 пина 2.54 мм: `GND / TX / RX / 3V3`, 115200 8N1 |
| **Отладка 2** | площадки JTAG на `PE4..PE7` (`TMS/TDI/TDO/TCK`) |
| **Под первый запуск** | перемычки 0 Ω на каждой рельсе, контрольные точки, земляные петли |
| **Индикация** | светодиоды: питание, заряд, заряд окончен |
| **Телеметрия** | напряжение батареи на `GPADC0` |

## Требования

1. **Стартует без карты.** Прошивка на SPI NOR, microSD только под ROM'ы и
   сейвы.
2. **Заливка прошивки без разбора корпуса** — USB-C + кнопка FEL снаружи.
3. **Правильная последовательность питания.** Выключатель запускает всю
   цепочку рельс через `PWR_EN`, а не рвёт один рельс. Тайминги — console/blocks/02-power.md §6.2.
4. **Экран разведён сразу под оба интерфейса** — SPI и i8080 16-бит, на одном
   FFC-40. Софт стартует на SPI, потом переезжает на 8080 без перепайки. Режим
   выбирается одним сигналом `IM_SEL`.
5. **Плата запускается по частям** — перемычки 0 Ω на рельсах, контрольные
   точки, boot-страпы перемычками, питание необязательных узлов через 0 Ω,
   работа без батареи. Порядок этапов — BOARD-draft.md.
6. **Автономность** — ориентир 1–1.5 Вт, 2 часа игры.
7. **Форм-фактор** — держать в двух руках: экран сверху по центру, D-pad
   слева, A/B/C/D справа, Start/Select снизу.

### Требования к софту, вытекающие из железа

- **Сейв писать по факту изменения PRG-RAM**, а не при выходе из игры: питание
  снимается движком в произвольный момент.
- **Гасить консоль примерно на 3.4 В по банке.** Защита банки срабатывает
  только на 2.4 В, а `VCC-IO` у F133 требует минимум 2.97 В.
- **Дисплей: шесть жёстких правил инициализации** — порядок `IM_SEL`/`RESET`,
  состояние шины `DB`, длительности сброса, потолок `DCLK` 25 МГц, `IO Disable`
  для неактивной ветки и запрет на SPI0 в режиме 8080. Список с обоснованием —
  console/blocks/06-display.md §6.9.

## Чего в ТЗ нет (сознательно)

Wi-Fi, Bluetooth, разъём наушников, вибромотор, второй геймпад, CVBS,
Ethernet, камера, тачскрин, power path, контроллер кнопки питания.

## Осталось выбрать

1. **Кварцы** — конкретные детали. Требования посчитаны: 24 МГц fundamental
   ±20 ppm `CL` 18 пФ корпус 3225, 32.768 кГц ±20 ppm `CL` 12.5 пФ корпус 3215,
   нагрузочные по 22 пФ NP0 (console/blocks/07-clock-reset.md §6.1, §6.3).
2. **Индукторы** 2.2 мкГн ×3 на buck'и — конкретная деталь. Требование к ней
   уже посчитано: `ISAT` ≥ 2 А, `DCR` < 50 мОм
   (console/blocks/02-power.md §7.2).
3. **MOSFET подсветки** — конкретная деталь. Требования посчитаны:
   N-канальный, логический уровень (`VGS(th)` ≤ 1.5 В, открыт при `VGS` = 2.5 В),
   `ID` ≥ 0.5 А, `RDS(on)` ≤ 100 мОм, SOT-23
   (console/blocks/06-display.md §7.1).
4. **Динамик** — критерии в BOARD-draft.md.
5. **Механика**: размер платы (~86×56 мм активная область + рамка),
   расположение кнопок, корпус, монтажные отверстия, высота кнопок. Сюда же
   **движковый выключатель** — тип решён (CHIPS.md §7), деталь выбирается
   вместе с корпусом, потому что торчит наружу.
